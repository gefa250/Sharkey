# 鲨译 Sharkey

鲨译 Sharkey 是 Windows 10/11 x64 上的 AI 桌面助手。按 `F8` 翻译选中文字，按 `F9` 截图识别并翻译；按 `F7` 打开外贸沟通、计算与拟写工作台。翻译、截图识别、外贸助手和识图转表格统一使用当前 AI 模型。

> [下载可运行版本](https://github.com/gefa250/Sharkey-Releases/releases/latest) · [查看更新记录](CHANGELOG.md) · [报告问题](https://github.com/gefa250/Sharkey/issues)

当前源码为 `0.3.2-dev`。此仓库存放源码，`Sharkey-Releases` 存放可运行程序及自动更新文件；下载页的最新版本以 GitHub Releases 为准。

## 开始使用

1. 在[下载页](https://github.com/gefa250/Sharkey-Releases/releases/latest)获取 `Sharkey-win-x64.exe`，运行后可在系统托盘找到鲨鱼图标。
2. 首次打开“设置 → AI 模型”，选择服务商，填写 API Key 和模型名称，再测试连接并保存。新用户默认进入 DeepSeek 配置；模型 ID 由用户填写，不预设未经验证的示例。
3. 选中文字按 `F8` 阅读译文；按 `F9` 框选文字或表格。截图上传给当前 AI 服务前会请求授权。
4. 按 `F7` 打开外贸助手，可在同一个会话里粘贴客户消息、添加截图或文档，整理询盘、拟写回复和核对报价；识图转表格可从托盘或截图窗口打开。

翻译目标默认使用智能模式：中文译成英文，其他语言译成简体中文；也可以在“助手偏好”指定固定目标语言。

## 快捷键与窗口

| 默认键 | 功能 |
| --- | --- |
| `F7` | 外贸沟通助手：在会话中发送消息、图片和文档，生成可编辑回复或仅获取沟通建议 |
| `F8` | 翻译当前选中的文字，显示紧凑的译文卡片 |
| `F9` | 框选屏幕区域，识别文字后翻译；原文可以修改并重新翻译 |
| `F10` | 打开设置 |
| `Ctrl+Alt+A` | 将屏幕框选截图添加到外贸助手当前会话，不自动发送 |

在“设置 → 快捷键”中可以直接按键录制自定义组合键。浮窗支持 `Esc` 收起、窗外点击收起、图钉固定、拖动和缩放。F9 工作区还可以切换上下或左右布局，并拖动原文与译文之间的分隔条。长文本可以滚动查看和选择复制。

## AI 模型与功能

- **AI 服务商**：DeepSeek、MiMo、Qwen 和自定义兼容接口。每家分别保存 API 地址、接口协议、模型 ID 和密钥，切换服务商不会覆盖其他草稿。
- **统一模型**：F8/F9、F7 和识图转表格都使用已保存的同一个当前模型；请求开始时固定配置，避免过程中途切换。截图与表格识别要求所选模型支持图片输入。
- **连接验证**：可先以未保存配置测试文本，再单独测试图片识别；修改连接字段后会清除过期的测试结果。
- **旧版本升级**：以前选择的 Google 或 Microsoft 翻译配置会归一到 AI 服务；旧 Google/Microsoft 密钥继续留在 DPAPI 加密配置中，但不再调用其翻译接口。若 AI 配置尚不完整，启动时会打开模型设置引导补齐。

设置分为“AI 模型、助手偏好、快捷键、通用”四页。修改先保存在独立草稿中，点击“保存并应用”后统一生效；取消、按 `Esc` 或关闭窗口会丢弃未保存修改。DeepSeek 余额只显示已保存的当前账户，设置打开时刷新，默认每 60 秒一次。

F7 采用对话式外贸工作区：左侧为可搜索的本机会话，右侧为对话与回复，底部输入区始终可见。“整理询盘”“对比报价”“核对变更”可填入起始要求，发送前可以自行修改。回答里的标题、列表和 Markdown 表格会按阅读格式显示，也可以选择、复制或切换到文本编辑。中文对照、建议、计算和来源放在可展开的核对区。回复语言可选择常用语言，也可直接填写小众语言及地区变体。

输入框支持直接 `Ctrl+V` 粘贴截图或文件，也可把 PNG/JPEG、PDF、DOCX、XLSX、CSV 拖入输入框；一次最多五张图片和五个文档。按 `Enter` 发送，按 `Shift+Enter` 换行。PDF 仅提取其中已有的文字；扫描版 PDF 请截取相关页面作为图片添加。文档文字在本机读取，按下“发送”后才连同消息发给当前 AI 模型。附件和对话按当前 Windows 账户加密保存。新建会话不会清除旧内容；左侧可搜索、恢复、重命名和删除。

可要求助手计算报价、毛利率、箱数、体积、运费与汇率，本地执行运算并展示公式。汇率、运价和报价参数应先由你确认。

联网搜索默认关闭。DeepSeek 官方账户优先使用原生搜索请求（额外模型费用），高级选项可选择独立的 Tavily 搜索。原生搜索仅在收到实际搜索结果时报告成功，不会在失败后静默切换付费服务；此开发版已通过模拟协议测试，尚未用真实付费账户验证，请先使用“测试搜索连接”。F9 数字核对等提示不能代替人工检查。

## 数据与网络

托盘菜单的“识图转表格…”支持框选截图、添加或粘贴图片。也可在 F9 译文窗口点击“转表格”，复用原截图。结果支持多表切换、逐格修改、复制到 Excel、导出 UTF-8 CSV；不会保留合并单元格样式，请核对识别结果。编号列导入 Excel 时建议设为文本，以保留前导零。

- API Key 保存在当前 Windows 用户的本地配置中，由 Windows DPAPI 加密；不会随源码仓库或发布包上传。
- F8 选中文字、F9 截图及表格识别会发送到当前 AI 模型服务；F7 附加图片在提交生成时发送，添加和粘贴本身不上传。启用搜索后，搜索词发送到选定的 DeepSeek 或 Tavily 服务。
- 外贸沟通文字、图片和附件提取的文字自动保存在 `%LOCALAPPDATA%\GlobalTranslator\Conversations`，使用当前 Windows 账户 DPAPI 加密；不能直接跨 Windows 账户解密。可在会话列表删除，不自动同步云端。不要依赖复制加密文件实现跨账户备份。
- 最近翻译和翻译缓存仍仅保留在内存；F8/F9 图片不写入翻译历史。
- 程序可手动检查 GitHub Releases 更新；下载更新时会校验 SHA-256。
- 启动联网或网络恢复后自动检查更新；重复网络事件会合并，同一版本每次运行只自动提示一次。关闭自动检查时也停止联网触发检查。
- 可在“设置 → 常规”调整自动检查更新间隔，默认每 24 小时；程序持续运行时也会检查。发现新版本会弹出更新窗口，由你决定是否下载安装。

## 从源码构建

项目使用 C#、WPF 和 .NET Framework，目标为 Windows x64。开发机需要对应的 .NET Framework 引用程序集及 MSBuild。现有脚本会生成单个 EXE：

```bat
build.cmd
test.cmd
```

输出位于 `bin\Release\Sharkey.exe`。如果该文件正被运行中的鲨译占用，可以指定另一个输出目录：

```bat
build.cmd bin\Preview\
test.cmd bin\Preview\Sharkey.exe
```

发布版本由 `VersionInfo.cs` 管理，打包流程见 [开发说明](DEVELOPMENT.md)。本机配置、密钥、构建输出和日志由 `.gitignore` 排除。需要反馈问题时，可以附上 Windows 版本、鲨译版本、复现步骤及“设置 → 常规”中的诊断摘要；提交日志前请自行检查其中的个人信息。

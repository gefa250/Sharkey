# 鲨译 Sharkey

鲨译是一款 Windows 全局翻译工具。它只在你明确按下快捷键时工作，普通选中文字不会自动触发翻译。

## 快捷键

- `F8`：翻译当前选中的文字
- `F9`：框选屏幕区域，OCR 识别后翻译
- `F10`：打开设置

三项均可在“设置 → 快捷键”中修改。点击录制框后直接按下功能键或组合键即可；字母和
数字需要搭配 `Ctrl`、`Alt` 或 `Shift`，保存时会检查三项快捷键是否重复。

## 翻译方式

设置页按用途分为四个分类：

- 翻译：统一管理目标语言、免费翻译、官方 API 和 AI 大模型
- OCR：DeepSeek Vision 截图识别和可选的 Windows 本地回退
- 快捷键：F8、F9、F10 及自定义组合键
- 常规：开机自启动和当前版本

翻译页采用“引擎类型 → 具体服务”两级结构：先选择免费、官方 API 或 AI 模型，再浏览
该类型下的具体服务。浏览和编辑不会改变当前引擎；配置面板中只有一个
“设为当前引擎”按钮，点击后仍需“保存并应用”才会影响 F8/F9。

翻译目标默认使用智能模式：简体或繁体中文译为英文，英文、日文、韩文及其他语言译为
简体中文；日文假名和韩文优先按非中文判断，中英混合按有效字符占比判断。纯数字、代码
和 URL 会保持原内容。也可以改为固定目标，支持简体中文、繁体中文、English、日语、
韩语等常用语言。

其他功能包括本地源语言判断、系统托盘，以及翻译后恢复原剪贴板。
翻译浮窗采用温和鲨鱼品牌与轻量玻璃外观，支持完整长文本、独立滚动、文字选择、
拖动、边缘缩放、收起和最大化。

## 构建与运行

系统要求：Windows 10/11、.NET Framework 4.8。

```bat
build.cmd
bin\Release\Sharkey.exe
```

应用会驻留系统托盘。双击鲨鱼托盘图标可打开设置。
“设置 → 常规”或托盘右键菜单都可以管理当前 Windows 用户的开机自启动；自动启动时
只驻留托盘，两处状态保持同步。

## 使用

1. 在任意应用中选中文字。
2. 按 `F8`，鲨译会短暂模拟 `Ctrl+C` 获取选区，并在鼠标附近显示译文。
3. 按 `F9`，拖动框选包含文字的屏幕区域；OCR 在本机完成，截图不会上传，识别出的文本再交给当前翻译服务。

OCR 默认使用 DeepSeek Vision 多模态模型读取截图，支持中英日韩及混合语言，不需要下载
Windows 多语言 OCR 包。视觉模型名称默认为 `deepseek-v4-flash-vision-exp`，复用
“AI 模型”页的 DeepSeek Base URL 和 Key；截图只在内存中编码并发送，首次启用时会请求
一次隐私确认。

如果视觉请求失败，可以在 `OCR → 离线回退` 中启用 Windows 本地 OCR。该回退只使用本机
已经安装的识别器，不会自动下载或安装语言包；未安装可用识别器时会保留错误提示。

OCR 翻译浮窗中的原文可以直接修改。修改后点击“重新翻译”，也可以复制原文或重新框选；
普通 `F8` 选词翻译的原文仍保持只读。
本地 OCR 会根据识别文字的坐标重建纯文本版式，保留截图中的换行、段落间隔、行首缩进
以及较大的列间距；字体、字号、颜色和图片等视觉样式不会复制到文本框。

鲨译不会静默安装或自动取得管理员权限，也不会修改 Windows 语言、键盘或首选语言配置。

部分管理员权限应用无法被普通权限进程读取；这种情况下请以管理员身份运行鲨译。密码框、受保护网页和部分自绘界面也可能禁止复制。

## 服务说明

- Google 免费：无需密钥，使用非正式网页接口。
- Microsoft 免费：无需密钥，使用 Bing 网页匿名会话。
- Microsoft 官方：填写 Azure Translator Key；区域资源还需填写 Region。
- Google 官方：启用 Cloud Translation API 后填写 API Key。
- AI 大模型：选择供应商会自动填写推荐的基础地址和模型名称，仍可手动修改；本地
  Ollama 等无需鉴权的服务可选择“自定义”并留空 Key。

模型接口会自动补全 `/chat/completions`，也接受已经包含该路径的完整地址。
自定义、DeepSeek、MiMo 和 Qwen 分别保存自己的 Base URL、模型名称和 API Key；
切换供应商会恢复对应配置，不会把一个厂商的密钥带到另一个厂商。所有厂商密钥仍由
Windows DPAPI 整体加密后保存在本机。
使用 AI 模型翻译时，结果浮窗会在原文上方显示紧凑的悬浮模型胶囊；自绘圆角菜单
只列出配置完整的模型：
DeepSeek、MiMo、Qwen 需要 Base URL、模型名称和 API Key；自定义公网接口同样需要 Key，
只有 localhost、局域网 IP 或本地域名允许留空，以支持 Ollama 等免鉴权服务。菜单底部的
“管理模型…”可直达 AI 大模型设置页。
切换后会立即用当前原文重新翻译，并将所选厂商作为下次默认值；浮窗不会在后台逐个
联网探测模型，避免额外请求和延迟。

模型翻译请求不会再使用 XML 标签包裹原文；若模型仍偶尔返回外层 `text` 或
`translation` 标签，客户端会只移除结果边界的包装标签，不影响译文内部内容。

免费方式依赖服务方未正式承诺稳定性的网页接口，可能受网络、调用频率或接口调整影响。重要或商业场景建议使用官方 API。

所有密钥均通过 Windows DPAPI 加密保存，只能由当前 Windows 用户解密。

## 开发版本与发布

当前开发版本由 `VersionInfo.cs` 统一管理，遵循语义化版本号。调整版本：

```powershell
.\scripts\Set-Version.ps1 -Version 0.2.0-dev
```

正式发布前将版本调整为 `x.y.z`、更新并提交 `CHANGELOG.md`，然后运行：

```powershell
.\scripts\Package-Release.ps1 -Version 0.2.0
```

脚本会要求 Git 工作区干净，执行 Release 构建与回归测试，校验 EXE 版本，生成 x64 ZIP、
发布说明、独立符号包和 SHA-256，并创建本地 `v0.2.0` 标签；不会推送远程仓库。
